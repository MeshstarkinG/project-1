# Internet Personality Test

온라인 행동을 10개의 축으로 읽어 12개 인터넷 페르소나 중 하나를 보여주는 정적 웹 테스트입니다.

## 구성

- `simulation.js`: 10개 성격 차원, 12개 유형 프로필, 12문항과 문항별 5개 선택지 및 가중치, 채점 알고리즘을 보관합니다.
- `main.js`: 질문 진행, 결과 화면, 차원 맵, 분포 시뮬레이션 UI를 제어합니다.
- `index.html` / `style.css`: 테스트의 시작 화면, 질문 화면, 결과 화면과 반응형 스타일을 제공합니다.

## 판정 방식

각 선택지는 하나 이상의 차원에 -3부터 +3까지의 가중치를 더합니다. 12문항의 누적 벡터를 12개 유형의 기준 벡터와 코사인 유사도로 비교하고, 가장 유사한 유형을 결과로 선택합니다. 결과 화면에서는 10개 차원의 누적 점수도 함께 확인할 수 있습니다.

## 검증

브라우저 콘솔에서 `PersonalityTest.runSimulation(10000)`을 실행하면 모든 문항에 무작위로 답한 10,000회의 유형 분포를 확인할 수 있습니다. 현재 설계에서는 12개 유형이 모두 발생하며, 낮은 빈도의 유형도 약 1% 이상 발생하도록 구성되어 있습니다.

브라우저에서 결과 화면의 `알고리즘 시뮬레이션 보기` 버튼을 누르면 같은 검증 결과를 화면에서 확인할 수 있습니다.
