# Internet Personality Test

온라인 행동을 10개의 축으로 읽어 12개 인터넷 페르소나를 탐색하는 정적 웹 테스트입니다. 홈, 테스트 플로우, 테스트 완료 후 결과 공개 화면을 제공합니다.

## 구성

- `simulation.js`: 10개 성격 차원, 12개 유형 프로필, 12문항과 문항별 5개 선택지 및 가중치, 채점 알고리즘을 보관합니다.
- `main.js`: 질문 진행, 결과 리빌, Identity Card 생성, PNG 다운로드와 공유 기능, 한국어/영어 전환을 제어합니다.
- `i18n.js`: 한국어/영어 UI 문구, 질문, 선택지, 유형 프로필, 성격 상세 정보, 차원명 번역을 보관합니다.
- `index.html` / `style.css`: 홈 화면, 질문 화면, 결과 공개 상태, 언어 토글과 반응형 스타일을 제공합니다.

## 판정 방식

각 선택지는 하나 이상의 차원에 -3부터 +3까지의 가중치를 더합니다. 12문항의 누적 벡터를 12개 유형의 기준 벡터와 코사인 유사도로 비교하고, 가장 유사한 유형을 선택합니다. 결과 화면에서 유형 설명, 태그, 10개 차원 맵을 함께 표시합니다.

## 검증

브라우저 콘솔에서 `PersonalityTest.runSimulation(10000)`을 실행하면 모든 문항에 무작위로 답한 10,000회의 유형 분포를 확인할 수 있습니다. 현재 설계에서는 12개 유형이 모두 발생하며, 낮은 빈도의 유형도 약 1% 이상 발생하도록 구성되어 있습니다.

프론트엔드는 12번째 답변 후 유형 결과, 설명, 강점, 초능력, 약점, 분위기, 디지털 동물, 이상적인 도시, 차원 맵을 즉시 표시합니다. 결과는 4:5 PNG로 다운로드할 수 있고 결과 링크 복사, Native Share API, X, WhatsApp 공유를 지원합니다. 링크에는 답변 시퀀스와 언어가 포함되어 동일한 결과를 복원합니다.
